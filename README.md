
#  RIVALIS — CS2 1v1 Matchmaking Platform


Веб-платформа соревновательного матчмейкинга в Counter-Strike 2 в формате 1v1 (RIVALIS). 

**Живая демонстрация проекта 24/7:** [http://45.140.19.240](http://45.140.19.240)

---

## Ключевые возможности

### 1. Авторизация и профили игроков
* **Steam OpenID OAuth**: вход в один клик через официальный Steam.
* **Автоматическая синхронизация профиля**: сайт подтягивает реальный никнейм и аватар игрока из Steam Community.
* **Быстрый вход по SteamID64**: резервный вход без перенаправления для удобства демонстрации.
* **Профиль игрока**: статистика ELO, винрейт, количество матчей/побед/поражений, история сыгранных матчей и уровень FACEIT (1–10).

### 2. Матчмейкинг 1v1
* Очередь поиска матча со счётчиком времени.
* Автоматический подбор соперников со схожим рейтингом ELO.
* Режим тестового матча с ботом для одиночной проверки функционала.

### 3. Вычеркивание карт (Map Veto)
* 7 официальных карт соревновательного пула CS2: Mirage, Inferno, Nuke, Dust II, Ancient, Anubis, Vertigo.
* Пошаговый драфт: игроки по очереди банят нежелательные карты, пока не останется одна решающая карта (**Decider**).
* Карточки карт с предпросмотром и статусом `BANNED`.

### 4. Интеграция с сервером CS2
* **RCON Protocol**: автоматическая отправка команды `changelevel` на игровой CS2 сервер после драфта.
* **MatchZy Webhooks**: прием событий окончания матча через API (`/api/matchzy/events`).
* **Подключение в 1 клик**: копирование консольной команды `connect <ip>:<port>; password ...` для вставки в консоль игры (`~`).

### 5. Рейтинговая система ELO
* Расчет изменения рейтинга по формуле ELO ($K=32$): $\approx \pm 25$ ELO за матч.
* 10 уровней мастерства FACEIT с фирменными цветовыми бейджами:
  * 1–3 уровень: Белый / Светлый
  * 4–7 уровень: Желтый / Зеленый
  * 8–9 уровень: Оранжевый
  * 10 уровень: Красный (PRO)
* Общий лидерборд игроков с поиском и фильтром по уровням.

## Технологический стек

* **Бэкенд**: PHP 8.3, Laravel 13, Livewire 4
* **Фронтенд**: Blade, Tailwind CSS (CDN), Alpine.js
* **База данных**: SQLite (быстрая реляционная БД без оверхеда)
* **Веб-сервер**: Nginx + PHP-FPM
* **Протоколы**: Source RCON Protocol, Steam OpenID 2.0, Webhooks
* **Хостинг**: Linux Ubuntu 24.04 LTS (VPS)
